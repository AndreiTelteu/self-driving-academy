## Dovezi de finalizare

Rezultat implementare: `src/fleet/eta.ts` calculează ETA și progresul din traseul real 041 al asignării 060 și starea cursei 061, fără ceas de perete, DOM sau renderer. Timpul rămas este profilul real al benzilor (lungime 033 / limită de viteză) distribuit exact pe costul 041 al etapei; ETA nominală și intervalul `etaMin..etaMax` sunt scalate de starea explicită a serviciului (`FREE_FLOW`, `CONGESTED`, `BLOCKED`), iar viteza instantanee este raportată, nu folosită ca bază. Progresul este forward-only, cu segment curent și fracțiune; reproiecția acceptă numai segmente din fereastra înainte, în toleranța laterală și fără sens opus. Motive închise: `ROUTE_MISSING`, `ROUTE_STALE`, `ROUTE_INVALID`, `POSITION_INVALID`, `OFF_ROUTE`, `SERVICE_BLOCKED`, `STALE_TICK`, `WRONG_RIDE`, `FOREIGN_VEHICLE`, `RIDE_TERMINAL`. Semnătura intrărilor plannerului plus replanificarea de verificare a etapei (aceeași secvență de benzi și același cost) refuză traseul vechi după o replanificare; lipsa rutei întoarce câmpuri `null`, niciodată `0` secunde certe.

Verificări executate și rezultat: `npm run typecheck` exit 0; `npm run lint` exit 0; `npm run format:check` exit 0 (All matched files use Prettier code style); `npm run check:architecture` exit 0 (188 fișiere TypeScript, probe negative 6+4+3); `npm run check:parameter-catalog` exit 0 (sincronizat); `npm test` 1252/1252 pass, exit 0; `tests/fleet/eta.test.ts` 13/13 pass, exit 0; `npm run ride:eta` 24/24 verificări, 32 curse finalizate, 311 eșantioane, overall PASS; `npm run ride:eta -- --check` exit 0. Logurile exacte sunt în `Docs/Evidence/064-eta/checks.txt` și `tests.txt`, iar transcriptul în `report.json`/`report.md`.

Fișiere și documente actualizate: `src/fleet/eta.ts` (nou), `src/fleet/index.ts` (export aditiv), `package.json` (script `ride:eta`), `tests/fleet/eta.test.ts` (13 teste), `tests/fleet/eta-fixture.ts`, `tests/fleet/eta-report.ts`, `scripts/run-eta-report.mjs`, `Docs/eta.md` (nou), `Docs/07-flota-si-curse.md` (paragraf de integrare) și `Docs/Evidence/064-eta/{README.md,checks.txt,tests.txt,report.json,report.md}`.

Limitări sau follow-up: ETA nu folosește viteza instantanee și nu prezice traficul; factorii de incertitudine sunt provizorii. Un cost 041 `0` (`origine == banda destinație`) produce ETA `0` deși pickup/dropoff fizic poate cere încă dwell în poligon. `061` nu retargetează o cursă activă, deci o rerutare reală este o asignare nouă, iar traseul vechi este refuzat cu `ROUTE_STALE`. Recuperarea/teleportarea în urmă în aceeași etapă poate produce `OFF_ROUTE` până la o poziție certificată; progresul nu este rescris automat. Integrarea HUD/browser, tarifarea, review-ul și sănătatea flotei rămân PBI-urilor 065, 073–075 și 209.
