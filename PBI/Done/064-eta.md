## Dovezi de finalizare

Rezultat implementare: `src/fleet/eta.ts` (exportat prin `src/fleet/index.ts`) oferă `createRideEta` cu `observe/setServiceState/currentTick/estimate/estimates/stats/dispose`. Citește ruta reală a asignării 060 (`pickupRouteLaneIds`/`tripRouteLaneIds`, `pickupCostSeconds`/`tripCostSeconds`) și starea reală 061; nu furcă id-uri, rute sau costuri. Baza de timp este geometria reală a benzilor 033 plus limitele de viteză ale hărții (`length / max(limit,1)`), distribuite astfel încât întreaga legătură să reproducă costul 041 stocat; golurile de conexiune contează ca distanță, nu ca cost. `plannedSpeedMps = metri bandă / cost legătură`. ETA este `plannedRemaining = fracția rămasă din banda curentă + timpii benzilor sufix`, cu `eta = planned/nominalFactor`, `etaMin = planned/maxFactor`, `etaMax = planned/minFactor`: FREE_FLOW 1,0 [0,9; 1,1], CONGESTED 0,5 [0,35; 0,65], BLOCKED indisponibil cu `SERVICE_BLOCKED`. Viteza instantanee este validată și raportată, dar nu este baza ETA. Progresul este forward-only (`traveled = max(previous, new)`), cu `segmentIndex`, `segmentLaneId`, `LANE`/`CONNECTION`, fracție, distanță și fracție rămasă. Reproiecția folosește identitatea reală a benzii 033: pozițiile off-route pot snap-ui doar înainte, în maximum 8 benzi și 4 m, niciodată pe un segment de sens opus; `OFF_ROUTE` și `POSITION_INVALID` sunt distincte. Motive închise: `ROUTE_MISSING`, `ROUTE_STALE`, `ROUTE_INVALID`, `POSITION_INVALID`, `OFF_ROUTE`, `SERVICE_BLOCKED`, `STALE_TICK`, `WRONG_RIDE`, `FOREIGN_VEHICLE`, `RIDE_TERMINAL`; rutele lipsă/învechite/invalide întorc geometrie `null`, niciodată `0 s`. Staleness-ul verifică semnătura intrării planner-ului plus o replanificare 041 proaspătă (benzi și cost identice); o rută creată după un replan este refuzată. Cursele terminale eliberează imediat ruta/progresul. Fără ceas de perete, bazat pe tick, fără DOM/Babylon/Rapier.

Raport: **32/32 cereri completate, 311 eșantioane** (141 pickup / 170 trip), **0 violări de monotonie**, **0 inversiuni ETA**, 64 încărcări de rută; 24/24 verificări PASS. Limitări sau follow-up: viteza instantanee nu este baza ETA, iar factorii de trafic sunt provizorii, nu trafic prezis. O rută 041 cu cost zero real (`origin == destination lane`) produce legitim ETA 0, în timp ce 062–063 cer totuși dwell fizic. 061 nu retargetează cursele active, deci un reroute este o asignare nouă, iar ruta veche este refuzată cu `ROUTE_STALE`. Teleportările înapoi în aceeași legătură produc `OFF_ROUTE` până la o poziție înainte certificată. Fără HUD/browser/FPS/Rapier/hardware.
