## Dovezi de finalizare

Rezultat implementare: `src/ui/taxi-hud-format.ts` (`073-taxi-hud-v1`) definește contractul de snapshot, parserul strict, `projectTaxiHud`, `modeView`, `rideStageView`, formatările de viteză/durată/distanță/ETA și limitele; `src/ui/taxi-hud.ts` oferă `createTaxiHud(host)` cu creare DOM o singură dată, `update(snapshot, nowMs)`, `getStats()`, `dispose()`; `src/app/taxi-hud.ts` leagă snapshot-ul la registry-ul 057, lifecycle-ul 061 și ETA 064. Viteza este readback-ul real 005 în m/s, afișat exclusiv în km/h (`round(m/s × 3,6)`); `null`/invalid → `—` + „Viteză indisponibilă”. Taxiul/profilul vin din registry (slot `#N`, id complet, clasă, profil și versiune în detalii), modul din proiecția acceptată 066/067 cu text și simbol (`A`/„Conduce AI-ul”, `M`/„Conduci · învățare oprită”, `L`/„Conduci · orașul învață”), niciodată doar culoare. Cursa din starea reală 061 → etapă/obiectiv/rută, cu ride id și stare tehnică în detalii. ETA/progresul folosesc estimarea reală 064 doar când cursa/taxiul/starea/leg-ul încă se potrivesc: `ESTIMATED` → `~durată`, `ARRIVED` → „La pasager”/„La destinație”, `UNAVAILABLE` → „Indisponibil”, fără observație → „Fără estimare”. Fără cursă → „Nicio cursă activă”, niciodată terminată; cursă a altui taxi → „Cursă a altui taxi”. Tick-urile vechi și ceasul regresiv aruncă; scrierile sunt la 10 Hz, cadrele identice nu scriu nimic, iar schimbările de mod/taxi/cursă/etapă ocolesc throttling-ul; detaliile sunt un `<details>` nativ, fără listeneri și fără capturare de tastatură.

Verificări: `npm run typecheck`, `lint`, `format:check`, `check:architecture` (194 fișiere + probe), `check:parameter-catalog` PASS; suita țintă `tests/ui/taxi-hud.test.ts` 12/12; `npm test` 1291/1291 PASS (1279 baseline + 12); `npm run hud:taxi -- --check` 23/23 checks, 7 scenarii, transcript curent. Probe de mutație: conversie greșită (38 vs 45), cursă lipsă randată terminată, etichetă de mod învechită, ETA lipsă randată `0 s` — toate respinse. Captură browser: 4 PNG la 1280×720, Chromium 151.0.7922.34, 28/28 checks (AUTO, MANUAL, SERVICE_BLOCKED, fără cursă), randând exact DOM-ul determinist `createTaxiHud`; nu este un cadru de simulare live, iar Playwright nu este dependență de proiect (scriptul folosește `PLAYWRIGHT_MODULE` și se sare curat când lipsește). Dovezi în [Evidence/073-hud](../../Docs/Evidence/073-hud/README.md).

Fișiere și documente actualizate: `src/ui/taxi-hud-format.ts`, `src/ui/taxi-hud.ts`, `src/app/taxi-hud.ts` (noi), `src/ui/index.ts`, `src/app/index.ts`, `scripts/hud-taxi-report.mjs`, `tests/ui/taxi-hud.test.ts`, [Docs/hud.md](../../Docs/hud.md) (nou), [Docs/27-reglaje-hud-si-camera.md](../../Docs/27-reglaje-hud-si-camera.md), `Docs/Evidence/073-hud/`.
