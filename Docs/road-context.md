# Context rutier autoritar (PBI044)

`createRoadContext(map, { priorityPolicy?, decisionPeriodTicks?, queryRadiusM? })` construiește un consumator semantic CPU în `autonomy`. Folosește API-urile publice032/033/034/035/038, fără Rapier, Babylon, timers, bus sau buclă proprie. Nu comandă vehiculul și nu emite oportunități, telemetrie, recompense sau dovezi learning.

Ownerul livrează `updateFrame(frame)` după pasul autoritar. Frame-ul are sessionId, worldEpoch, tick, vehicule cu id/incarnation/poziție/heading/access/viteză/rază, intenția explicită de mișcare sau null, distanțe SI furnizate per relationId, obstacole/zone identificate, snapshoturi036 per mișcare și completitudinea fiecărui domeniu. Absența observațiilor nu certifică completitudinea; flagurile trebuie furnizate explicit. Un snapshot incomplet nu transformă absența în eliminare fizică. Observațiile anonime addBox nu capătă IDs inventate.

Integrarea022 poate folosi entityId și BodyIdentity.generation drept id/incarnation, poziția transformului și viteza autoritară de la același tick. Headingul hărții este atan2(forward.z, forward.x), cu zero pe+X; forward-ul vehiculului se obține prin rotirea axei locale+Z cu quaternionul autoritar, fără oglindire. Access TAXI/CIVIL este furnizat de ownerul semantic al flotei și nu se deduce din clasa mecanică. Modulul nu se abonează implicit la bodyport și nu inventează un bridge live ori o completitudine a obstacolelor care nu există încă.

Datele sunt plain, validate adânc și copiate/frozen înaintea folosirii; getters, obiecte exotice, arrays sparse sau cu prototip/metode proprii sunt respinse. Pozițiile sunt finite în ±1.000.000m, heading în ±π, viteza0–100m/s, raza vehiculului0–100m. Geometria obstacolelor/zonelor respectă034. Un frame invalid nu modifică snapshotul acceptat, cache-ul sau istoricul identităților. În timpul pregătirii sunt interzise reentry/reset/dispose. Repetarea canonical-identică a aceluiași tick este idempotentă; un conținut diferit, un tick vechi, o lume/sesiune veche ori un snapshot036 stale/contradictoriu este respins.

`getContext(id, { force? })` returnează snapshot readonly sau null pentru un vehicul absent. `context.tick` rămâne tick-ul observației efective. Cache-ul implicit păstrează decizia maximum6tick-uri până la următoarea citire; citirile pot avea context mai vechi decât `getStats().tick`, fără a-l restampa. `invalidate(id, incarnation)` marchează urgent numai identitatea live exactă; următoarea citire recalculează din cel mai recent frame acceptat chiar în aceeași perioadă AI. `force:true` cere întotdeauna context nou. Ownerul conectează invalidarea la schimbări urgente ale lumii; motorul nu recitește și nu avansează controllerul036 sau038. Cadenta AI nu schimbă timpii oportunităților ori tick-urile telemetriei.

Banda rezultă din geometria orientată033, inclusiv heading și separarea verticală. Liderul este cel mai apropiat centru strict înainte pe aceeași bandă orientată, apoi ID lexicografic; gapM este distanța longitudinală minus cele două raze, plafonată inferior la zero. Vecinii laterali, sensul opus, podurile și benzile necorelate rămân vecini spațiali, fără a deveni lideri. Raza este anvelopa semantică furnizată de owner, nu calibrare nouă a colliderului. Query-ul local este o sferă3D de60m implicit; nu este un sweep sau o dovadă că drumul este liber.

Intenția route identifică intersectionId/movementId existent în035. Semnalul se aplică numai pe banda de intrare a acelei mișcări sau când vehiculul este geometric în poligonul intersecției, cu anvelopa verticală±1,5m. În afara acestora rămâne UNKNOWN_ROUTE; intenția offroad nu dă GREEN. Contextul păstrează snapshotul036 concret și tick-ul său. Mișcarea necunoscută este respinsă la admitere; ruta absentă, observația lipsă și intersecția fără program au stări distincte, fără GREEN implicit.

Conflictele statice sunt relațiile035 ale intenției valide. `conflictVehicleIds` include traficul local cu intenții incompatibile valide; nu certifică ocuparea sau un orizont complet. `priorityRelations` reutilizează politica explicită038 și `predictPriorityArrival` numai pentru distanțe/clearance furnizate de owner. Un datum pe altă relație/rută cunoscută este respins. Cu route=null, datums pot rămâne diagnostice inactive și nu sunt aplicate; astfel lipsa rutei nu moștenește o predicție. Lipsa datumului și discontinuity dau arrival=null. Nu există istorie de dwell/traversare, interpolare, verdict legal sau apel ascuns038.observe. Fiecare gap este explicit UNKNOWN și coverage LOCAL_ONLY, chiar când lista locală e goală sau frame-ul declară vehicule complete: raza locală nu certifică traficul pentru horizonul038. Evaluarea globală și dovezile la60Hz aparțin ownerului038, separat de samplingul AI.

`ROAD_CONTEXT_LIMITS` fixează110vehicule,96obstacole,512zone,128vertexuri/zonă,128datums/vehicul și4096/frame,4096snapshoturi de semnal,110intrări cache și1024identități distincte per epoch pentru toate cele trei kind-uri. Kind-ul unei identități rămâne stabil într-un epoch. Incarnation nu scade; după o eliminare confirmată prin completitudinea domeniului trebuie să crească pentru reintroducere. Tombstones sunt păstrate fără LRU și împart plafonul1024. La capacitate frame-ul este refuzat, fără trunchiere ori fabricarea unui epoch. `reset(sessionId, worldEpoch)` este un reset explicit de owner: pentru aceeași sesiune epoch trebuie să crească; schimbarea sesiunii este explicită. Cache/istoric/index se golesc; callbackurile vechii lumi sunt respinse. `dispose()` este idempotent.

Fingerprintul canonical are maximum16Mi code units (până la32MiB payload UTF-16, fără overhead). O estimare conservatoare se verifică înainte de JSON.stringify; frame-urile mari combinate pot fi refuzate chiar dacă plafoanele individuale încă permit datele. Acesta este un plafon de admitere, nu memorie RAM exactă sau calibrare de gameplay. Toate limitele sunt provizorii pentru fixture-ul timpuriu și necesită verificare pe harta/trafficul real.

Indexul este construit pentru fiecare frame complet pregătit, apoi înlocuiește atomic indexul anterior. În timpul pregătirii există maximum două indexuri populate: fiecare are cap-urile034, deci vârful poate avea32768referințe și cel mult32768celule,1436entități și131072vertexuri de index, plus un index gol fără date. Copia validată temporară a noului frame este separată; pentru zone poate adăuga încă65536vertexuri înainte de eliberare. Un eșec disposează indexul candidat. `getStats().index` arată numai indexul curent, nu acest vârf tranzitoriu. Cache-ul păstrează maximum110contexte; snapshoturile deja returnate sunt responsabilitatea callerului. Contextul păstrează geometriile obstacolelor locale, IDs de zone și metadata/predicții bounded, fără o listă de istorii de frame.

Proiecțiile de bandă se reutilizează numai în cadrul aceluiași frame acceptat, maximum110 intrări (inclusiv rezultate null). Orice frame nou acceptat golește proiecțiile, independent de cache-ul deciziilor AI. Frame-urile respinse sau canonical-identice nu alterează această ownership; reset/dispose o golesc. `getStats().laneProjections` raportează intrările curente; acest cache nu păstrează geometrie istorică ori proiecții din tick-uri anterioare.

Baseline-ul și probele sunt în [raportul Evidence044](Evidence/044-road-context/report.md). Benchmarkul măsoară costul contextului fresh cu force:true; cache-ul/invalidarea/completitudinea/prioritatea se verifică separat. Distanțele fixe10m/clearance5m din fixture sunt date sintetice explicite, nu măsurări ale mișcării sau dovezi de continuitate. Probele Node sunt suplimentare CPU/memorie; nu aprobă FPS, întregul tick autoritar, laptopul sau gate-urile hardware.
