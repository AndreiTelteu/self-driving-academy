## Contract

Event kinds: RIDE_TERMINAL, VEHICLE_DISTANCE, BLOCKED_INTERVAL, COLLISION, VIOLATION.
Metrics: completedRides, failedRides, cancelledRides, terminalRides, completionRate, averagePickupSeconds, averageTripSeconds, totalDistanceM, vehicleKilometres, rideDistanceM, blockedIntervals, blockedSeconds, blockedFraction, collisions, collisionsPer100VehicleKm, violations, violationsPerOpportunity.
Unavailable reasons: NO_EXPOSURE, NO_RIDES, NO_DISTANCE, NO_FLEET, NO_OPPORTUNITIES.
Idempotency memory: 8192 keys, 1024 code units per
identity.

Rules: denominators use the whole fleet from counts(), hidden and unselected vehicles included; zero exposure or a missing distance/opportunity denominator is UNAVAILABLE with value:null; a real zero with a real denominator stays AVAILABLE with value:0; events are idempotent by eventId and every aggregate is incremental; historyScans is 0; out-of-order ticks are accepted and counted deterministically by sum/count/min/max; a metric value carries exactly one unit and a closed unavailable reason.
