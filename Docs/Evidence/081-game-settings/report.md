# 081 game settings report

Machine-readable transcript: [report.json](report.json). Generated by `npm run game:settings`; it
contains no wall-clock value, random value or browser-only state.

Version: `081-game-settings-v1`. The report drives the real `createGameSettingsPanel` adapter, the pure
draft/formatting operations and the 009 `SettingsStore` composition over deterministic inputs. Display
units are presentation only; every saved value stays SI.

## Contract

Policy: Setări dispozitiv · nu modifică profilul învățat, AI-ul sau stilul flotei.

Audio: UNAVAILABLE · PBI_148_PENDING (Indisponibil · 148).

Ranges: steeringSensitivity 0–100, returnRate 0–100, speedAttenuation 0–100, throttleRamp 0–100, brakeRamp 0–100, cameraMotion 0–100, fov 60–100°, resolutionScale 0.5–1.

Rules: display units convert SI m/s and m for presentation only; physics, telemetry and profiles stay SI; camera, units and graphics changes preserve input.bindings, playerId, scenario and the control revision; a comfort change increments input.control.version exactly once per save; reset restores display/camera/comfort/graphics defaults and preserves input.bindings; audio is explicitly unavailable until 148; no volume or mute control is created; the learned-style editor is a separate surface and is absent from this panel.
