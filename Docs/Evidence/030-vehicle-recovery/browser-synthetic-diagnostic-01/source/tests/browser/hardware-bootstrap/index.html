Proba bootstrap pe hardware real

Conectează alimentarea, închide aplicațiile GPU și păstrează tabul vizibil. Proba completă durează aproximativ 25 de minute: cinci repetări, colector oprit și pornit, cu 30 s încălzire și 120 s măsurate pentru fiecare.

Pregătit. Nu schimba tabul în timpul măsurării.
