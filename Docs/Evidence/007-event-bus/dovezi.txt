Implementare:
- API public createEventBus, subscribe/unsubscribe, publish, advanceTick, advanceWorldEpoch, getStats, dispose.
- Validare unknown prin schema SimulationEvent existentă; copii înghețate, sessionId/worldEpoch strict.
- Ordine sincronă: apeluri publish, apoi order crescător/ordinea înregistrării.
- Dedup per epoch păstrează identitatea înainte de listeners. Duplicate/retry nu reexecută niciun listener.
- Conflicte de identitate, reentrancy, tick vechi, lumi străine și capacități depășite sunt respinse.
- Listener failures sunt colectate, restul listeners continuă. At-most-once, fără rollback/tranzacții externe.
- Ledger plafonat fail-closed; nicio evictare. Epoch crește explicit, vechea lume rămâne invalidă.

Limitări: dedup volatil pe durata busului/epochului; după restart/recreare trebuie ledger durabil propriu. Async listeners interziși prin tip și documentație; busul nu anulează efectele unui callback care încalcă contractul. Efectele externe, input temporar mare, durata listeners și exact heap nu sunt plafonate/tranzacționate de transport.
