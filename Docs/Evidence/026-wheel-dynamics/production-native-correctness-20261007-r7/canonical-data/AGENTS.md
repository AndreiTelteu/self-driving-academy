# Instrucțiuni pentru proiect

Engine-ul ales este Babylon.js. Planul curent este în Docs/README.md.

Înainte de implementarea unui PBI, citește PBI/AGENTS.md și documentele modulului. Respectă dependențele și mută fișierul To Do → In Progress → Done.

**Nu declara un PBI finalizat înainte de mutarea fizică în PBI/Done și de verificarea cu PBI/Validate-Board.ps1 -RequireDone 'ID'.** Schimbarea câmpului status nu înlocuiește mutarea fișierului.

Pentru lucrul exclusiv la documentație sau organizarea backlogului, nu începe și nu închide artificial task-uri de implementare a jocului. Aceste instrucțiuni nu autorizează executarea întregului backlog.
