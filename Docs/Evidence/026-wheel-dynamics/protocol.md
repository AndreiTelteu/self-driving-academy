AFTER must use the same fixture and measurement channels. Report incremental wheel readback separately. Retention is bounded to four wheels per admitted vehicle and no history in production. Cleanup must verify disposed identities and owned registries; twenty full-capacity lifecycle cycles are a separate test.

Calibration uses repeated native worlds on the same flat ground,180ticks settling,10/20/30m/s braking,8/20m/s fixed geometric-radius turns, two mechanical classes, native wheel friction readback, curb excursion and airborne/contact transitions. Dry/reduced-adhesion fixture values must be actual native mechanics, not just UI labels. Readonly render poses must derive suspension, steering and continuous wheel rotation from physical state; presenting/interpolating them cannot change any native state.

The default dry surface preserves every existing native tire/ground value. Suspension baseline remains authoritative; adjust constants only when real curves justify a change.
