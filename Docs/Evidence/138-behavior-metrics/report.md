# 138 behavior metrics report

Machine-readable transcript: [report.json](report.json). Generated by `npm run metrics:behavior`.
The report contains no wall-clock timestamp, no random value and no machine-local measurement, so
`--check` compares it exactly.

Version: `138-behavior-metrics-v1`. The report drives the real `createBehaviorMetrics` accumulators and
the real 082 metric adapter over deterministic opportunities and speed samples.

## Contract

Event kinds: OPPORTUNITY_RESOLVED, SPEED_SAMPLE.
Unavailable reasons: NO_OPPORTUNITIES, NO_REACTION_SAMPLES, NO_STOP_DWELL, NO_SPEED_SAMPLES, NO_LIMIT, NO_ELIGIBLE_SPEED, NO_HEADWAY_SAMPLES.
Idempotency memory: 8192 keys, 1024 code units per
identity. Reaction ticks are converted at 60 Hz; one accepted speed
sample is declared as 0.1 s.

Rules: the opportunity denominator is the set of distinct (opportunityId, occurrence) identities; a repeated frame of the same occurrence is DUPLICATE and changes no numerator or denominator; 10 Hz and 60 Hz duplicate streams produce identical denominators and numerators; an empty denominator is UNAVAILABLE with value:null; a real zero with a denominator is AVAILABLE 0; success comes from the 086 opportunitySuccessOutcomes; a violation comes from the real failure table; speed and headway distributions keep bounded histograms and never retain a full history; over-limit duration uses only samples with a certifiable limit and a declared sample interval; historyScans is structurally 0 and the snapshot is frozen.
