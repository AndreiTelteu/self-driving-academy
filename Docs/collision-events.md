# Contacte native și incidente028

`PhysicsProbe` expune portul de coliziune din vehicles. `collisionIdentity(id)` și `collisionForColliderHandle(handle)` întorc token-uri înghețate canonice, valabile numai cât înregistrarea exactă trăiește în lumea proprietară. ID-ul este unic între VEHICLE și OBSTACLE. `addCar` înregistrează colliderul real; `addNamedBox` admite explicit un obstacol static sau dinamic și opțional sensor. Vechiul `addBox` rămâne anonim. `removeCollisionEntity(token)` nu poate elimina o reînregistrare cu același nume/handle. `collisionSource` oferă doar verificarea read-only a identității.

`readCollisionContacts()` copiază contactele reale înainte de eliberarea manifoldului Rapier. Intensitatea este suma impulsurilor normale `contactImpulse(i)` în N*s pe `numContacts()`, fără conversie din forță și fără contactForce EventQueue. Admiterea native este `contactDist <= normalizedAllowedLinearError * lengthUnit` OR impuls pozitiv; astfel include toleranța resting nativă și CCD predictiv cu impuls real la gap pozitiv. Gap pozitiv peste toleranță cu impuls0 este exclus. Nu este o afirmație de penetrare geometrică exclusivă. Erorile/capacitățile sunt amânate până după unwindingul callbackurilor native, deoarece Rapier0.21 nu eliberează temporarele prin finally când callbackul aruncă.

Sunt enumerate numai candidate pornind de la vehicule. Ground, sensors și collider-ele fără înregistrare sunt filtrate. Perechile obstacle-only nu sunt enumerate. Counter-ul0 pentru obstacle-only sau sensors nu demonstrează absența contactelor/intersecțiilor din întreaga lume; probele de excludere verifică lipsa incidentelor. Rapier handle este un numeric finit opac, inclusiv fracționar; identitatea incidentului folosește serialul monoton al înregistrării, nu handle-ul.

`createCollisionEpisodes(context, source, options?)` este pure vehicles, fără dependență de EventBus/simulation. `update(tick, contacts)` primește snapshot complet: primul tick arbitrar, apoi tick-uri consecutive; retry echivalent la același tick este idempotent, iar conflictul sau gap-ul este respins atomic. Perechile canonice agregă manifold-uri repetate. Contactul persistent emite o singură dată. După separare, recontactul emite dacă onset-ul precedent este cu cel puțin cooldown60tick în urmă (frontieră inclusivă). Recontactul prematur suprimă întregul nou episod, fără emitere ulterioară doar pentru că cooldown-ul a expirat. Istoricul separat expiră la frontieră; episoadele prezente nu expiră cât sunt active. Ordinea de livrare este key-ul perechii seriale canonice, invariant la permutarea arrayului pentru aceleași înregistrări.

`drain(publish)` este sincron și păstrează exact suffix-ul neacceptat când publisherul aruncă, inclusiv null/undefined. Verifică token-urile înaintea fiecărei publicări; remove/reuse poate elimina incidente stale. Un tick nou este respins cât există pending. Callbackurile nu pot reintra în mutația core-ului. `reset` cere aceeași sesiune și epoch strict mai mare; `dispose` eliberează istoricul/coada. Overflow respinge întregul update, fără truncare ori prefix de stare.

Compoziția `createCollisionEventAdapter({context,physics,eventBus,episodes?})` trăiește în simulation și importă vehicles. Constructorul verifică sessionId/epoch/disposed din EventBusStats înainte de efecte. Proprietarul apelează `beforePhysicsStep(tick)`; numai `ready:true` permite exact un `physics.step`. Apoi `captureAfterPhysicsStep(tick)` verifică serialul native și traduce exact varianta007 COLLISION, cu eventId=incidentId, entityIds=[vehicleId,otherEntityId], payload={vehicleId,otherEntityId,impulseNs}. ID stabil include session namespace, epoch, perechea serială și onset tick. Două vehicule aleg vehicleId lexicografic după ID.

Pending blochează admiterea unei avansări noi. `retryPublications()` repetă numai livrarea, niciodată fizica. Evenimente delivered/duplicate consumă coada; eșecurile listenerelor sunt efecte deja acceptate și sunt raportate fără repetare. Diagnosticul păstrează cel mult64 mostre eventId/listenerId/errorType, cu total/omitted explicit și fără grafuri arbitrare de erori. O eroare readback/admission după pasul real marchează faulted partialtick; proprietarul trebuie să facă recuperare explicită, fără replay fizic sau epoch inventat. Eticheta de capture greșită poate fi corectată înainte de readback, păstrând admiterea originală.

`collisionStepSerial()` este contorul real al pașilor native reușiți, incrementat imediat după world.step. Snapshot.physicsStepSerial este valoarea lui la readback. Adapter.getStats.physicsStepSerial este ultima valoare capturată cu succes de adapter și poate rămâne în urmă după o eroare/callback cu avansare externă. Admiterea reverifică serialul după callbackurile de publicare și nu permite suprascrierea unui preparedTick cu alt tick.
