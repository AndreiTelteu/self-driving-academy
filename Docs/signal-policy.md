# Signal policy 050 — red/green compliance

Status: implementation with targeted local validation. PBI050 board state and publication are owned by the parent; the cost/memory probe, tests and limitations are recorded in [the 050 evidence](Evidence/050-signal-policy/README.md).

`projectSignalProfile` reads only the four050 keys (`red_stop_probability`, `green_start_delay`, `red_stop_line_offset`, `late_red_brake_threshold`) from an already published profile through the existing registry, with units probability/s/m/s and map capacity80. It grants no estimator or publication capability, so LEARNED provenance stays rejected for all four keys while MANUAL_TUNING becomes accepted exactly as for the earlier policy keys. `evaluateSignalPolicy` re-validates the supplied profile numbers through `validateParameterValue`, so a forged profile object is rejected by unit/range, not trusted.

The exact input schema is sessionId, worldEpoch, actor, decisionTick, speedMps, seed, opportunityKey, profile, observation. `speedMps` is the authoritative ego longitudinal readback at the decision tick. observations are the authoritative036 read for the subject's own movement: version, units, tick, signalId, intersectionId, movementId, phaseId, state, phaseElapsedS and distanceToStopLineM (front datum, positive before the line, null without authored line geometry). `signalOpportunityKey` builds the canonical opportunity identity with `createStableId` over session, epoch, vehicle, incarnation, intersection, movement and the phase start tick; the owner supplies it, so the module never invents a global event index.

The compliance sample is addressed, not drawn: `randomUnit(deriveOpportunitySeed(vehicleSeed, opportunityKey), 'red-compliance', 0)` uses the006 seed addressing, so re-evaluating the same opportunity reproduces one value and no per-tick counter or hidden state exists. Sampling again only happens at a new identified opportunity (for example the next phase occurrence).

A GREEN phase releases (`PROCEED`/`GREEN_RELEASE`) unless the vehicle is still effectively stationary (at most0.1 m/s) and `phaseElapsedS` is below `green_start_delay`, in which case it holds and reports `START_DELAY`/`GREEN_START_DELAY`, which is how a slow start differs from an immediate one. A RED or YELLOW phase samples once: below `red_stop_probability` the driver stops (`STOP_LINE_APPROACH` while `distanceToStopLineM - red_stop_line_offset > 0`, otherwise `STOP_LINE_HOLD`), which is where the offset is applied; at or above the probability the driver is non-compliant and only brakes while the remaining time to the line `distanceM / max(speed, 0.1 m/s)` is at least `late_red_brake_threshold`, otherwise the red is already committed and the decision is `CROSS_RED_BY_PROFILE`. An unauthored stop line cannot be stopped for and is reported as the crossing policy limitation rather than a fabricated stop.

Unsignalled roads are explicit (`NO_SIGNAL`, no stop). A missing profile, a stale observation (age above six ticks) or a future observation yields `UNKNOWN`/`UNAVAILABLE` with no sample and no requested stop. `signalBehaviorFacts` composes into045 without changing any other fact: it raises `stop: RED_BY_PROFILE` only for a requested stop, clears only its own fact on release, keeps an independent STOP-rule or requested stop intact and is fenced by exact version and profile version. Precedence is explicit: a red intent wins over an independent STOP-rule fact.

Admission bounds:110 actors per packet, six-tick observation age,256/128/8192 UTF-16 units for identities/profile/opportunity keys, distances within ±100000 m, speed within ±100 m/s, `phaseElapsedS` up to3600 s, zero retained actors/opportunities/history. Rejection is atomic and does not read accessor properties; the documented policy remains pure and deterministic.

Evidence at commit `8059f60d`: 832 project tests pass, the nine050 tests cover a free signal, a stopped slow start versus a fast one, the applied offset with the independent reference oracle, one sample per re-evaluated opportunity across ten decision windows and four re-reads, running a red versus late-red braking on both sides of the horizon, unavailable facts, and the real045 composition. The targeted native probe measures the added cost of the new path on the real036/033/044/045 fixture: p95 `+0.0191 ms` per10 Hz decision with five preserved repetitions. See [the evidence](Evidence/050-signal-policy/README.md) for the manifest comparison and the memory counters.

Limitations: the sample identity is the caller's opportunity key, so a changed key is a new opportunity; the authored stop-line datum, the036 observation and the actuation of the reported intent (046/047/024) stay caller-owned and are not certified here. No browser, GPU, FPS or integrated-game acceptance is claimed; the calibration labels remain provisional.
