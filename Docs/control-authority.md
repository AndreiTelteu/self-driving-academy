The owner admits an entire finite request batch before calling024. Contradictory simultaneous PLAYER claims and duplicate requests reject the whole batch, never last-writer wins. Foreign context/tick, stale tokens, accessors, extra/symbol fields and malformed commands reject before physical advancement or keyboard clearing.024 remains the physical command arbiter: accepted PLAYER replaces AUTONOMY in that same tick, using existing raw/effective controls and brake/handbrake constraints. No driving pose or velocity is rewritten.

After successful024.step, the owner records the actual accepted seat, identities and tick before calling clearOldPlayer with only the departed exact token. MANUAL↔LEARNING on the same body preserves the filter/ramps. A handoff clears/disposes the old addressed filter, while host composition explicitly creates a fresh addressed filter/packet for the new seat. An old PLAYER packet stays addressed to the old body and is ignored there after handoff; it is never retargeted.

External callback effects cannot be rolled back. Throwing or returning a non-void result causes terminal KEYBOARD_CLEAR fault after physical acceptance. Reentrant mutation is rejected. The fault reports the accepted physical tick/seat; the host must stop/pause the world. A native actuation failure causes CONTROLLER_ACTUATION and reports that a complete tick was not accepted, without claiming rollback of partial external effects. Registration/removal callback faults do not claim a newly accepted physical tick. Further mutations cannot proceed through a fault. Reset requires a real new session or later epoch, different fresh empty controller and matching ports. Same-epoch reset cannot bypass a fault. The host owns old controller/native/input disposal; this module does not police every globally created factory.

Registration checks the actual native identity and delegates controller acceptance before changing owned records. Capacity is110 vehicles/requests, one seat,256-code-unit IDs/session IDs, zero retained batches/history. Reset/dispose releases strong token/seat/controller/port references; injected controller/native world stay host-owned. Existing native generation and024 registration fences are reused without a duplicate tombstone ledger.
